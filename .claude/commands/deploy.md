Deploy: update docs, commit, and push.

Run the full deploy pipeline:

1. **Update documentation** — Run the /udoc skill to update docs for any recent changes.

2. **Commit all changes** — Stage all modified and new files, then create a git commit with a descriptive message summarizing the changes.

3. **Push to remote** — Push the commit to the remote repository on the current branch.

Report what was committed and pushed when done.
